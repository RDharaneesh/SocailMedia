## 🚀 Quick Start Commands

### Windows (Easiest)
```bash
# Just double-click
start.bat
```

### Mac/Linux
```bash
chmod +x start.sh
./start.sh
```

### Manual Setup
```bash
# Terminal 1
cd Socialmedia/backend && npm install && npm run dev

# Terminal 2
cd Socialmedia/frontend && npm install && npm run dev
```

Then open: **http://localhost:5173**
